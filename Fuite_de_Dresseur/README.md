# Fuite de Dresseur

Mod pour Gen1Recomp 0.1.96 permettant de tenter de fuir les combats de
dresseurs dans Pokemon Rouge, Bleu et Jaune.

## Fonctionnement

- L'option **Fuite** utilise la formule normale de la premiere generation.
- Une tentative peut echouer si le Pokemon actif est moins rapide.
- Les chances augmentent apres chaque echec.
- Un echec consomme le tour et permet au Pokemon adverse d'attaquer.
- Une reussite quitte le combat et valide le dresseur comme vaincu afin que
  le combat ne se relance pas au retour sur la carte.
- Les combats sauvages, Safari, tutoriels et Link restent inchanges.
- Aucune ROM et aucune sauvegarde ne sont modifiees.

## Installation

Telechargez le dossier `Fuite_de_Dresseur` sous forme de ZIP, avec
`manifest.json` a la racine de l'archive, puis utilisez **Import Mod** dans
Gen1Recomp. Activez le mod et acceptez la permission `engine_internals`.
