# Pokemon Trad Fr

Traduction française pour Pokémon Rouge, Bleu et Jaune avec Gen1Recomp.

## Version

1.0.0

## Installation

1. Téléchargez le fichier ZIP depuis la section Releases.
2. Dans Gen1Recomp, ouvrez **MODS** puis **Import mod .zip**.
3. Activez **Pokemon Trad Fr**.
4. Redémarrez complètement le jeu.

Cette version conserve la police native de Gen1Recomp afin d’éviter la disparition du texte dans le gestionnaire de mods.

> Aucune ROM Pokémon n’est incluse dans ce dépôt.
