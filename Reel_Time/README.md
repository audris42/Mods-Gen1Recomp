# Réel Time — version 1.0.0

Mod pour Gen1Recomp affichant l'heure locale de l'ordinateur dans le coin supérieur droit pendant l'exploration.

## Installation

1. Placer le dossier `Reel_Time` (ou son fichier ZIP) dans le dossier `mods/` de Gen1Recomp.
2. Ouvrir le gestionnaire de mods.
3. Activer **Réel Time** et accepter la permission `engine_internals`.
4. Relancer le jeu si le gestionnaire le demande.

Le gestionnaire permet d'activer ou masquer l'horloge et de choisir entre les formats 24 h et 12 h.

## Sécurité

Ce mod lit uniquement l'heure locale fournie par le système. Il ne modifie aucune ROM et n'écrit rien dans les sauvegardes Pokémon.
