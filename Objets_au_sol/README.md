# Objets au sol — Gen1Recomp

Mod pour **Pokémon Rouge, Bleu et Jaune** avec Gen1Recomp 0.1.98 ou plus récent.

## Fonctionnement

Les objets cachés qui n'ont pas encore été ramassés sont signalés sur la carte par un petit losange animé.

Appuyez sur **A** depuis la case du losange ou une case directement voisine. L'orientation du personnage n'a pas d'importance. Le marqueur disparaît dès que l'objet est récupéré.

Les objets déjà visibles sous forme de Poké Ball restent inchangés.

## Installation

1. Téléchargez `objets-au-sol-1.0.0.zip`.
2. Placez le ZIP dans le dossier de mods utilisé par Gen1Recomp.
3. Activez **Objets au sol** dans le gestionnaire de mods.
4. Redémarrez la partie si Gen1Recomp le demande.

## ROM

Ce mod n'ouvre, ne patche et ne réécrit aucune ROM. Il utilise uniquement les données de carte déjà chargées en mémoire par Gen1Recomp.
