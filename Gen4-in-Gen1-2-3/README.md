GEN4 IN GEN.1/2/3
Version 1.0.0

Ce mod remplace uniquement les images de combat avant et arriere des Pokemon
numero 001 a 151 par celles de Pokemon Or.

Il ne change ni les statistiques, ni les attaques, ni les types, ni les cris,
ni les rencontres, ni les evolutions.

Installation :
1. Desactiver ou supprimer le test "Pikachu - Sprites Pokemon Or".
2. Ouvrir le gestionnaire de mods de Gen1Recomp.
3. Importer Gen4-in-Gen.1-2-3-1.0.0.zip.
4. Activer "Gen4 in Gen.1/2/3".
5. Lancer Pokemon Rouge, Bleu ou Jaune.

Les images proviennent du cache local genere par Gen1Recomp depuis la ROM
Pokemon Or fournie par l'utilisateur. Ne pas redistribuer ce mod publiquement.
